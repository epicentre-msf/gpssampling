GPS Sampling

GPS Sampling is a fork of GeoSampler, originally created by Epicentre (MSF). The original application and its sampling methodology would not be possible without R and Shiny.

This fork is maintained independently for internal use and released under the WTFPL license.

Contributions are welcome in a number of ways:

  • Code patches via pull requests
  • Documentation improvements
  • Bug reports and patch reviews
  • Testing

If you encounter any problem with GPS Sampling, or you would like to give suggestions, please use the GitHub issue tracker at https://github.com/epicentre-msf/gpssampling/issues.

Learn GPS Sampling

The contents of the Learn GPS Sampling tutorials are based on the field experience of Epicentre and MSF epidemiologists from the original GeoSampler project, and are licensed under the Terms and Conditions of the GNU Free Documentation License v1.3.

For the original version of this application, please visit the official GeoSampler website.
